## 华为交换机有三种端口模式，Access、Trunk、Hybrid
### Access端口
* 端口只属于一个VLAN
* 接收无vlan tag包时，自动添加端口所属vlan的tag.
* 发送数据时剥离vlan tag.

### Trunk端口
* 端口支持传输多个vlan
* 接收数据时，如果带tag，只允许allow-pass列表内vlan通过；如果不带tag，添加native vlan的tag
* 发送数据时，仅对Native vlan数据剥离标签、其他vlan保留标签

### Hybrid端口
* 端口支持传输多个vlan
* 支持配置pvid，为接收的无tag帧添加pvid的tag
* 支持显式配置是否剥离vlan tag
* 在配置hybrid端口允许通过的vlan时，必须要指定动作，tag还是untag.

* 接收方向：

    * 收到无tag帧：根据端口的 PVID 打上对应的 VLAN Tag，然后在该 VLAN 内进行交换转发。
    * 收到有tag帧：检查该 VLAN ID 是否在端口允许通过的 VLAN 列表（无论是 tagged 还是 untagged 列表）中。如果在，则接收并在该 VLAN 内进行交换转发；如果不在，则丢弃。

* 发送方向：

    1. 交换机决定将一个帧从某个端口发出。

    2. 端口检查这个帧的 VLAN ID。

        * 如果这个 VLAN ID 在端口的 untagged vlan 列表中，则在发送前剥离 VLAN Tag，以 Untagged 帧的形式发送出去。

        * 如果这个 VLAN ID 在端口的 tagged vlan 列表中，则在发送时保留 VLAN Tag，以 Tagged 帧的形式发送出去。

        * 如果这个 VLAN ID 既不在 untagged vlan 列表，也不在 tagged vlan 列表中，则这个帧无法从该端口发出（被丢弃）。

    **PVID 在发送方向上不起决定作用！它只影响入方向 Untagged 帧的打标。**
